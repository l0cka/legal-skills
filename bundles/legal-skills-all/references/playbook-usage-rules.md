# Approved playbook usage rules

The jurisdictional drafting playbook records the firm's standing drafting
positions. It is maintained by the firm's senior lawyers and stored with the
approved precedents in the private deployment.

## Rules

1. **Apply a covered position.** Apply an approved playbook position when it
   clearly covers the client's express instructions and the selected precedent.
   Note the applied position in the change summary.
2. **Keep facts separate.** Never use the playbook to supply a client fact.
   Names, addresses, gifts, shares and appointments come from the instruction
   table.
3. **Flag conflicts.** If the client's express instructions conflict with the
   playbook, do not resolve the conflict. Draft supported content, mark the
   affected location and add the point to the drafting-issues register.
4. **Preserve the precedent when silent.** If the playbook does not address a
   point, preserve the approved precedent text unless the client's instructions
   require a change. Flag any required but unsupported change.
5. **No new drafting position.** Never invent, combine or improve clause text.
   A clause outside the approved precedent and playbook is a solicitor drafting
   issue.
