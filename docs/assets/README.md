# Brand assets

- `legal-skills-logo.svg` / `.png` — the mark: an italic section sign on a
  navy document with a gold folded corner. The SVG is self-contained (the
  glyph is an outline, not live text).
- `legal-skills-banner-light.png` / `-dark.png` — the README banner, chosen by
  the reader's colour scheme. The result card and its `READY FOR HUMAN REVIEW`
  stamp are illustrative, not a real skill output.

Palette: navy `#14294A`, ivory `#F7F1E3`, gold `#C99A3E`, review green
`#1F6F5F`.

Typefaces, all under the SIL Open Font License 1.1: Fraunces (wordmark and
the section-sign outline), Inter (tagline) and IBM Plex Mono (card text).
