# Review Psychosocial Risk Controls

Compare the supplied documents with the provisions and codes that apply, and
list gaps with their source. The review never certifies compliance and never
decides that a control is adequate or reasonably practicable.

Read the [source and control method](../../references/whs-source-and-control-method.md)
first and work from the [WHS framework reference](../../references/whs-framework.md).

## Workflow

1. Fix the documents and context.
   - Record each supplied document (title, version, owner, effective date),
     the workplaces and jurisdictions, the workforce, and known psychosocial
     hazards or reported incidents as described.
   - Without supplied documents, prepare the review framework for the
     jurisdiction with labelled placeholders for the documents needed, and
     return `NOT READY` for the gap findings only.
2. Select the governing provisions.
   - Model WHS jurisdictions: the jurisdiction's WHS Regulations
     psychosocial provisions and the approved code of practice on managing
     psychosocial hazards where the jurisdiction has approved one.
   - Victoria: the OHS (Psychological Health) Regulations 2025 and the
     supporting compliance code.
   - Record each source's version and commencement; label codes as codes.
3. Check the risk management cycle.
   - Hazard identification: whether each common psychosocial hazard the
     facts or the code list is considered, including job demands, low job
     control, poor support, role clarity, bullying, harassment including
     sexual harassment, aggression and violence, traumatic events, remote or
     isolated work, and poor workplace relationships.
   - Assessment and controls: whether controls address duration, frequency
     and severity of exposure and how hazards interact, and whether the
     hierarchy the provision requires is followed. Record what the document
     says; do not judge whether the control is enough.
   - Consultation: records of consulting workers and health and safety
     representatives.
   - Review: triggers and dates for reviewing controls, including after a
     report or incident.
   - Victoria only: any prevention plan or written record the regulations or
     compliance code call for.
4. Record gaps.
   - For each gap: the provision or code clause, what the documents show,
     what is missing, a gap type (`no evidence`, `partial`, `inconsistent
     with document`, `cannot be determined`) and the evidence state.
5. Route overlaps.
   - Sex discrimination positive duty and discrimination merits to
     `$assess-discrimination-and-positive-duty`; Fair Work policy terms
     (right to disconnect, flexible work) to `$review-workplace-policy`;
     individual complaints and investigations to the responsible lawyer.
6. Verify.
   - Route every regulation, code and commencement relied on to the
     jurisdiction's checker and record the evidence state.
7. Report using the result contract and name the responsible lawyer.

## Result contract

Lead with `READY FOR HUMAN REVIEW`, `READY WITH QUALIFICATIONS`, `NOT READY`
or `OUTSIDE SCOPE`.

```text
Documents: <title; version; owner; effective date>
Context: <workplaces and jurisdictions; workforce; known hazards or reports>
Governing sources: <regulation or code; status (regulation / approved code / compliance code / guidance); version; checker used; evidence state>
Gap table: <provision or clause; documents show; missing; gap type; evidence state>
Routed overlaps: <issue; skill or reviewer>
Gaps in inputs: <documents or facts needed; resolver>
Human decision gate: <responsible lawyer; decisions required>
Limitations: <gap review only; no compliance certificate; no adequacy or reasonably practicable conclusion>
```

## Fail closed

Return `NOT READY` for the gap findings when no documents are supplied, after
preparing the framework. Route workers compensation claims for psychological
injury, complaint investigations and discrimination merits to `OUTSIDE
SCOPE` with the specialist named. Never certify compliance, never conclude
that a control is adequate or reasonably practicable, never draft or rewrite
the PCBU's policy text, and never present a code of practice or compliance
code as a regulation.
