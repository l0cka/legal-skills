# Firm context

This folder is an empty slot. The bundle ships no firm material.

After you upload the bundle, a firm may add files here (or to the host's
knowledge store) so the skills can use them:

- A firm profile for the skills that read one: drafting, review playbook,
  employment, deadlines, governance, AI governance, AML/CTF, consumer and
  competition, and legal triage. Each skill's `references/` or the shared
  `references/` folder holds the matching profile schema.
- House style, precedents and clause preferences.
- The firm's diary system of record and the named confirmer for dates.

Rules:

- Keep client, matter and privileged material out of this folder.
- A profile is the firm's own document. A person at the firm approves it; the
  skills never mark a profile approved.
- Name each file for what it is, for example `drafting-profile.md`.
- Anything here applies only to the workspace it was uploaded to.
