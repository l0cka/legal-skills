# No-code procedure: check the Australian Privacy Principles

Use this when the host cannot run code. It replaces the inventory comparison
of [this skill](SKILL.md) with a side-by-side comparison a person makes.

A spreadsheet cannot do the digest step honestly, so each layer's digest is
not computed here and never stated, estimated or invented. A person with code
computes it when the result must carry one. The comparison below is exact
text comparison by a person.

Method: [APP verification method](references/app-verification-method.md).

## Steps

1. Establish the official versions first with the legislation checkers named
   in the skill. Without opened official sources the status is
   `APP FRAMEWORK NOT VERIFIED – DO NOT RELY`.
2. For each of the four layers, put the earlier and later text side by side:
   APP text, application perimeter, regulations and codes, guidance.
3. Treat any difference in wording, heading, clause range or source URL as a
   change in that layer.
4. Fill one row per APP or layer item:

| Layer | Item (APP number or provision) | Earlier source and version | Later source and version | Same text? | Change noted |
| --- | --- | --- | --- | --- | --- |

5. Apply the fail-closed statuses in the skill's step 5. A manual comparison
   supports `APP FRAMEWORK VERIFIED` only when the official sources were
   opened and every layer was compared.
6. In the Inventory line write `hash not computed, a person with code computes it`,
   and state in the result that the comparison was manual.
