# Estate planning drafting

Vocabulary for the `australian-estate-planning` plugin.

## Language

**Approved precedent**:
A centrally maintained, human-designed source document approved for the
jurisdiction and document type. It is kept unchanged and is not committed to
this repository.
_Avoid_: generic template, sample

**Working copy**:
The matter-specific draft prepared from an approved precedent. The approved
source remains unchanged.

**Instruction sheet**:
The completed client-facing document used as a factual source for the matter.
_Avoid_: intake form

**Instruction table**:
The structured set of fields extracted from an instruction sheet or provided
by the practitioner. Every value has provenance. It is the only source of
matter-specific factual values used in a draft.

**Review marker**:
`[REVIEW REQUIRED – <missing fact or unresolved decision>]`, inserted at each
location affected by an unresolved issue.

**Drafting-issues register**:
The list matching every review marker to its document location, provenance and
required solicitor decision.

**Approved playbook**:
Connected drafting guidance that may identify approved clause alternatives. It
cannot supply client facts or create a new drafting position. The workflow
applies covered positions and flags conflicts or unsupported choices for the
responsible solicitor.
